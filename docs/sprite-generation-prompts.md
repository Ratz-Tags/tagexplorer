## Generation Instructions

1. **Resolution**:
   - **Sprite Sheet**: 2048x1024 (square) or 2560x1216 (portrait)
   - **Individual Sprites**: 1024x1024 (square) or 832x1216 (portrait)

2. **File Organization**:
   - Place all sprites in `/public/assets/companion/` at their **original resolution**
   - Use the filenames specified above for each outfit and emotion
   - Keep files at original resolution in the folder (post-processing/resizing handled by code if needed)

3. **Outfit Swapping**: The code can detect and swap between outfits by checking for files matching the pattern `companion-{outfit}-{emotion}.png`
